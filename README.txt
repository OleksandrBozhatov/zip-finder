Соседние индексы: установка на iPhone

PWA работает только по https, поэтому папку нужно один раз выложить на бесплатный хостинг.
Ничего устанавливать на компьютер не нужно, всё делается в браузере.

1. Распакуй этот архив (получится папка zip-pwa).
2. Открой https://app.netlify.com/drop, войди (можно через Google) и перетащи папку zip-pwa на страницу.
   Через несколько секунд получишь ссылку вида https://что-то.netlify.app
3. На iPhone открой эту ссылку в Safari, нажми «Поделиться» и выбери «На экран "Домой"».
4. Запусти приложение с иконки, нажми «База не загружена» и выбери архивы стран.
   Архивы скачиваются в Safari с https://download.geonames.org/export/zip/ (например DE.zip, FR.zip
   или allCountries.zip для всех стран сразу). Распаковывать не нужно.
   Важно: база, загруженная в Safari, не видна приложению с экрана «Домой», и наоборот.
5. Дальше поиск работает без интернета.

Обновление: замени файлы на Netlify (снова перетащи папку в тот же сайт, раздел Deploys)
и поменяй строку VERSION в sw.js, чтобы телефон забрал новую версию.

Иконка (маршрут A и B) временная. Если есть свой логотип, замени файлы в папке icons с теми же размерами.
